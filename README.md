### 🚀 Projeto em destaque

#### [Sistema de Gerenciamento de Estoque/Patrimônio — SCE Uro-Nefrologia](https://github.com/MarcoTulioSilv/Sistema_gerenciamento_estoque)

Sistema desktop arquitetado e desenvolvido do zero para resolver o rastreio de insumos hospitalares/farmacêuticos, com evolução posterior para controle de patrimônio.

- 🏗️ Arquitetura em **monólito modular** (autenticação, estoque, relatórios, notificações, admin e dados)
- 🗄️ Persistência via **SQLAlchemy (ORM)** sobre **MySQL**
- 📄 Importação automática de **DANFE (NF-e)** para entrada de produtos
- 🔐 Autenticação com **bcrypt** e dados sensíveis protegidos com **criptografia Fernet**
- 📊 Geração automática de relatórios e **notificações por e-mail** (APScheduler)
- 🏷️ Controle de patrimônio por **etiqueta com QR Code**, lido via celular, usado também para inventário
- 📦 Empacotado com **PyInstaller** + instalador **Inno Setup**, com **auto-updater** e **backup automático**
- 📈 **Em produção**, utilizado por 7 usuários — orquestrando 200 itens de consumo e 400 itens de patrimônio
